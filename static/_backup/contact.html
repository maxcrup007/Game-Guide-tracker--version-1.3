FAQ
How do I request a game to be added? ▼
Go to the Request page and fill out the form with the game title and any details. We'll research and add it soon.
Can I add my own notes to any game? ▼
Yes! Click Edit on any card to add your own notes. Notes support full Markdown — headings, lists, images, links, and more.
What is the markdown upload feature? ▼
You can upload a .md file directly to a card using the Upload .md button. The file content replaces the card's notes and is saved to the database.
How do I open notes in StackEdit? ▼
Click "Read more →" on any card with notes, then click "Open in StackEdit ↗" in the detail view. Your notes will be pre-loaded into the StackEdit editor.
Who can access the admin panel? ▼
Only superusers with credentials can access /admin. Admins can manage categories, tags, platforms, statuses, announcements, and review requests.
